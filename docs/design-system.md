# Design System NalarAman

Dokumen ini merangkum token desain dan prinsip antarmuka NalarAman berdasarkan PRD Bab 13.

## 🎨 Palet Warna Resmi
| Nama Token | Nilai Hex | Penggunaan |
|---|---|---|
| `--primary-purple` | `#6D28D9` | Tombol primer, tautan aktif, aksen utama |
| `--accent-purple` | `#8B5CF6` | Sorotan, hover state, indikator interaktif |
| `--dark-purple` | `#2E1065` | Judul, header hero, teks tebal beraksen |
| `--lavender-bg` | `#F5F3FF` | Latar belakang halaman |
| `--white` | `#FFFFFF` | Latar belakang kartu/panel |
| `--text-primary` | `#172033` | Teks tubuh utama |
| `--text-secondary` | `#64748B` | Keterangan, placeholder, teks pendukung |
| `--border-neutral` | `#E5E7EB` | Border standar |
| `--border-lavender`| `#DDD6FE` | Border kartu & panel utama |

## 🚦 Status Semantik Risiko
| Level | Warna Teks | Warna Latar | Ikon |
|---|---|---|---|
| **Risiko Rendah** | `#15803D` | `#DCFCE7` | ● Rendah |
| **Risiko Sedang** | `#B45309` | `#FEF3C7` | ▲ Sedang |
| **Risiko Tinggi** | `#B91C1C` | `#FEE2E2` | ■ Tinggi |

## 📐 Tipografi & Dimensi
- **Font Family**: `'Plus Jakarta Sans', 'Inter', -apple-system, system-ui, sans-serif`
- **Border Radius**:
  - Tombol: `8px`
  - Kartu & Panel: `12px`
  - Pill / Badge: `999px`
- **Box Shadow**: `0 4px 20px -2px rgba(46, 16, 101, 0.06), 0 2px 6px -1px rgba(46, 16, 101, 0.04)`
